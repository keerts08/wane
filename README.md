# Wane
Daydream Submission (hecatomb)

Wane is a top-down shooter where you don’t get stronger, you get weaker. Clear each level’s enemies and collect the coins, then choose what to sacrifice: health, speed, shooting speed, or knowledge. Every choice is permanent, so each run asks you to survive with less.

Controls: WASD to move, mouse to aim, left click to shoot.

A remake of my earlier Godot game Hecatomb, rebuilt for Hack Club Savepoint.
